# Python environment

Use `ragdemo/Scripts/python.exe` for this project's Python commands.
Install all future project Python dependencies with `ragdemo/Scripts/python.exe -m pip`.
Do not install project dependencies into the system, Conda base, or Codex bundled Python.

# Knowledge base

The source PDF is `output/terraria/泰拉瑞亚30条饰品合成路径.pdf`.
Use `rag_kb.py build` to rebuild `knowledge_base/terraria` from the PDF.
Keep each complete recipe together and preserve source page numbers and version notes.
